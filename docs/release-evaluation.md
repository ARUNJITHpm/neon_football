## Frozen evaluation

`tools/release_evaluation.py` reproduces the existing Part 06 dummy shadow fixture with checksummed source/input/configuration provenance. It never writes the official score or interprets generated labels as independent venue truth. It reports raw counts, descriptive Wilson recall/Poisson rate intervals and virtual decision latency. Its release flag is false, field metrics null and field gates pending. The public fixture is development evidence, not a blind holdout; no clustering-adjusted interval or real clock/render timing exists.

## Software validation and practical limits

Live WAL backup/restore preserves committed goals, command idempotency and stored evidence without changing the source. Reopen interrupts match time and retires pending evidence. Invalid/tampered/incomplete bundles and existing targets fail. Unsupported database versions stop before journal/migration changes. Audit inspection reconciles events, goal projection, command acknowledgments and immutable trigger presence; detected runtime faults latch quarantine rather than mutate scoring.

The abrupt child-exit test leaves a committed goal and an uncommitted score change; on reopen the goal survives and the partial write is rolled back. This exercises process termination and SQLite recovery, **not a physical host-power or filesystem durability guarantee**. Existing tests cover stuck/reconnecting capture, delivery lag, quota/write failures, sensor disconnect/reboot/invalid packets, stale inference/evidence, network/client reconnect and candidate retirement. No live inference or serial workers are composed into scoring, and no physical failure drill is claimed.

Closed-session retention tests use only generated bytes and preserve active/held media, audit logs and registry metadata. The default policy is disabled. The bounded supervisor has simulated exit-sequence checks; actual service installation/hung-process recovery remains pending. Operational telemetry exposes measured capture/drop/age/lag and host-process CPU samples where available, and null memory/temperature/serial/inference queue metrics rather than invented health.
